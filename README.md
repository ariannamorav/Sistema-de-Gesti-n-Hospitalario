# Sistema de Gestión Hospitalario

Sistema académico desarrollado en **2024** como proyecto para la asignatura de **Bases de Datos** durante la formación en Ingeniería de Sistemas.

El proyecto consiste en una aplicación orientada a la gestión de información relacionada con un entorno hospitalario, permitiendo trabajar con diferentes entidades y procesos como **pacientes, médicos, tratamientos y consultas**.

> Proyecto desarrollado con fines académicos y de aprendizaje.

## Descripción

El sistema fue desarrollado con el objetivo de aplicar de manera práctica los conocimientos adquiridos en la asignatura de **Bases de Datos**, especialmente en la organización, gestión y consulta de información.

La aplicación cuenta con diferentes módulos que permiten interactuar con la información del sistema hospitalario, incluyendo la gestión de pacientes, médicos, tratamientos y consultas.

A través del proyecto se buscó comprender cómo estructurar y administrar la información de un sistema compuesto por diferentes entidades relacionadas.

## Módulos

Entre los principales módulos desarrollados se encuentran:

* Gestión de pacientes
* Gestión de médicos
* Gestión de tratamientos
* Gestión de consultas
* Consulta y gestión de información hospitalaria

## Tecnologías

`Java` `MySQL` `NetBeans` `XAMPP`

## Base de Datos

El proyecto utiliza **MySQL** como sistema de gestión de bases de datos y **XAMPP** como entorno para la ejecución y administración de la base de datos durante el desarrollo.

La aplicación permite trabajar con información relacionada con las diferentes entidades del sistema hospitalario y sus relaciones.
